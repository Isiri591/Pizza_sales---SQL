# 🍕 Pizza Sales Analysis (SQL Project)

## 👤 Author
Hi, I'm **Isiri**. This project uses SQL to analyze pizza sales data and extract meaningful business insights.

## 📌 Business Context
**Larana Pizza** aims to deliver high-quality pizzas while creating great customer experiences.

### 🎯 Vision
To become a loved and innovative pizza brand delivering quality, convenience, and memorable moments.

### 🚀 Mission
To provide delicious pizzas using fresh ingredients with excellent service and customer satisfaction.

## 📂 Dataset
- orders.csv  
- order_details.csv  
- pizzas.csv  
- pizza_types.csv  

## 🛠 Skills Demonstrated
- SQL Joins
- Aggregations (SUM, COUNT, AVG)
- Grouping & Filtering
- Business Data Analysis

## 📊 Business Questions Solved
### 📦 Orders & Revenue
- Total number of orders placed  
- Total revenue generated  

### 🍕 Product Insights
- Highest-priced pizza  
- Most common pizza size  
- Top 5 most ordered pizza types  

### 📈 Category Analysis
- Quantity ordered by pizza category  
- Category-wise distribution  

### ⏰ Time-Based Analysis
- Orders distribution by hour  
- Average pizzas ordered per day  

### 💰 Revenue Insights
- Top 3 pizzas by revenue  
- Revenue contribution by pizza type  
- Cumulative revenue over time  

### 🏆 Advanced Insights
- Top 3 pizzas by revenue within each category  

## 📌 Key Insights 
- 🍕 Best-selling pizza: **Mozzarella Pizza**
- ⏰ Peak order time: 12:00 PM – 1:00 PM
- 💰 Highest revenue category: Classic Category
- 📊 Most popular size: Large
